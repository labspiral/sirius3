# Sirius3 documentation

> API reference: Sirius3 Core/UI 1.17.0 (public features)

[English](README.md) | [한국어](README.koKR.md)

These guides cover public Core/UI 1.17 APIs and editor workflows. Install compatible
Core, UI and Dependencies packages; their version numbers can differ. Check that the
installed packages support the required features when adopting an example or menu.

Start with the framework guide, then create/select an entity and edit it in
PropertyGrid. Use **Font Edit** for font-file editing. Review processing conditions
before Marker Preview or actual marking; simulation is a separate display operation.

## Sirius3 1.17.0 highlights

1. [Editor](EditorUserManual.md): interactive creation and Grip editing, with a
   clickable mode indicator and Arc/Ellipse center handles.
2. [Font Editor](FontEditorUserManual.md): edit existing Sirius fonts or convert
   installed fonts to CXF/LFF/DOT; CXF is the default conversion output.
3. [Document and entities](DocumentUserManual.md): PDF page images, synchronized
   page selection and improved child editing in composite objects. See
   [MCP file access](MCP.md) for the host-accessible-path default.
