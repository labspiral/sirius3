[Sirius3] 2D Scanner Field Correction User Manual
==================================================

1. 개요 (Overview)
------------------
본 매뉴얼은 SCANLAB RTC 제어기를 사용하여 스캐너의 2D 필드 보정(Field Correction)을 수행하는 Sirius3 2D 보정 윈폼의 사용 방법을 설명합니다. 이 절차를 통해 스캐너의 물리적인 장착 오차 및 기하학적 왜곡을 정밀하게 보정하여 가공 정밀도를 향상시킬 수 있습니다.

2. 준비 사항 (Prerequisites)
----------------------------
- RTC 제어기와 스캐너가 정상적으로 연결 및 초기화되어 있어야 합니다.
- 기본 보정 파일(.ctb 또는 .ct5)이 필요합니다.
- 가공 테스트를 위한 자재와 실제 가공 위치를 정밀하게 측정할 수 있는 측정 장비(예: 머신 비전 등 측정 장치)가 필요합니다.

3. 보정 절차 (Step-by-Step Procedure)
------------------------------------

Step 1: 기본 정보 설정
- Source File: 원본 보정 파일을 선택합니다. (.ctb는 16비트, .ct5는 20비트 방식)
- Target File: 보정 결과가 저장될 경로와 파일명을 지정합니다.
- K-Factor: 현재 사용 중인 스캐너의 보정 계수(bits/mm)를 입력합니다.

Step 2: 보정 그리드(Grid) 설정
- Rows / Cols: 보정 포인트를 측정할 행과 열의 개수를 설정합니다. (홀수 권장, 예: 3x3, 5x5, 9x9, 17x17 와 같이 반복할때마다 증가시킨다)
- Row / Col Interval: 각 측정 포인트 간의 간격(mm)을 입력합니다.
- 'Reset' (마우스 우클릭 메뉴): 설정한 그리드 크기로 측정 데이터 테이블을 초기화합니다.

Step 3: 데이터 입력 (Data Entry)
- 가공된 그리드 패턴을 측정한 후, 각 위치별 오차값(dx, dy)을 그리드에 입력합니다.
- 입력 형식: "dx, dy" (예: "0.01, -0.005")
- 셀 색상 가이드:
  * 빨간색: 오차 거리가 매우 큰 경우 (입력 오류 확인 필요)
  * 명암 변화: 오차가 작을수록 밝은 회색으로 표시되어 데이터의 분포를 시각적으로 확인 가능합니다.

Step 4: 파일 변환 (Convert)
- 'Convert' 버튼을 클릭하여 입력된 데이터를 바탕으로 새로운 보정 파일을 생성합니다.
- 성공 시 결과 메시지가 표시되며 보정 알고리즘이 적용된 파일이 Target 경로에 생성됩니다.

Step 5: 하드웨어 적용 (Apply)
- 'Apply' 버튼을 클릭하면 생성된 Target File을 RTC 제어기의 보정 테이블(Table 1)에 로드하고 선택합니다.
- 이후 가공부터는 보정된 좌표계가 적용됩니다.

4. 주요 기능 설명 (Key Features)
-------------------------------
- Import/Export (마우스 우클릭): 측정 데이터를 텍스트(.txt) 파일로 내보내거나 다시 불러올 수 있어 데이터 백업 및 재사용이 용이합니다.
- Convert From .dat: 외부 측정 장비에서 생성된 .dat 형식의 원본 데이터를 직접 변환할 수 있습니다.
- Plot Raw (Debug): 보정 파일 내의 내부 데이터를 시각적으로 플로팅하여 보정 상태를 미리 확인할 수 있습니다. (Preliminary 기능)

5. 주의 사항 (Cautions)
-----------------------
- 데이터 입력 시 dx, dy는 '측정값 - 이론값(타겟값)'의 오차량을 의미합니다.
- 그리드 설정 변경 후에는 반드시 'Reset'을 눌러야 하지만, 이 경우 기존에 입력한 데이터가 삭제되므로 주의하십시오. (삭제 전 Export 권장)
- 보정 포인트가 많을수록 정밀도는 높아지지만 측정 시간이 오래 걸리므로 적절한 개수를 선택하십시오.
