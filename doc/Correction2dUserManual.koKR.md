# 2D 스캐너 필드 보정 안내서

> API 기준: Sirius3 Core/UI 1.17.0 (공개 기능)

[English](Correction2dUserManual.md) | [한국어](Correction2dUserManual.koKR.md) | [전체 안내서](README.koKR.md)

## 1. 보정이 필요한 이유

1. 2D 스캔헤드는 X·Y 미러로 빔 방향을 바꿉니다. 미러 각도와 평면 위의 실제 위치는
   완전히 비례하지 않습니다.
2. 일반적인 집광 구조에서 광축으로부터의 거리는 대략 `r = f × tan(θ)`입니다.
   `f`는 초점 거리, `θ`는 빔 각도입니다. f-theta 렌즈는 이를 `r = f × θ`에 가깝게
   만들어 왜곡을 줄입니다. 그래도 설치·정렬 오차와 렌즈 공차는 남습니다.
3. 호환 RTC의 `.ct5` 같은 측정 기반 보정 테이블은 필드 위치별 잔여 오차를 줄입니다.
   `KFactor`는 전체 bits/mm 배율이며 필드 보정을 대신하지 않습니다.

실제 헤드·렌즈·작업 거리에 맞는 보정 파일을 사용합니다.
전체 절차는 [보정 개요](CalibrationUserManual.koKR.md)를 참고합니다.

## 2. 측정 격자 준비와 가공

1. 원본 보정 파일을 보존하고 결과 파일은 다른 이름으로 지정합니다. 측정 전 선택한
   헤드와 원본 파일의 KFactor를 확인합니다.
2. `CreateGridsForm`에서 격자 패턴을 만들고 보정 화면에도 같은 행·열 수와 간격을
   사용합니다. 격자 간격의 단위는 mm입니다.
3. 장비가 정한 저출력 절차로 기준 위치를 가공한 뒤 보정된 카메라나 측정기로 실제
   XY 좌표를 기록합니다. 격자를 Reset하면 기존 측정 데이터가 지워집니다.

처음에는 성긴 격자로 확인하고 잔여 오차에 따라 점을 늘립니다. 점이 많아지면 측정
시간과 잘못된 측정점의 영향도 커집니다.

## 3. 측정 오차 입력

화면은 **dx = 측정 X − 기준 X**, **dy = 측정 Y − 기준 Y**를 mm로 표시합니다.
예를 들어 기준 `(10, 5)`, 측정 `(10.010, 4.995)`이면
`dx = 0.010`, `dy = -0.005`입니다.

두 값은 공백이나 쉼표로 구분할 수 있습니다.

```text
0.010 -0.005
0.010, -0.005
```

카메라 좌표를 스캐너 좌표로 바꾼 뒤 입력합니다. 축 방향·회전·미러·원점·단위를
맞추고 기준 격자와 같은 행·열 순서를 사용합니다. 누락·중복·유효하지 않은 측정값을
먼저 제거합니다. 셀 색상은 큰 오차를 찾는 보조 표시이며 합격 여부는 수치로 판단합니다.

## 4. 변환·적용·검증

1. 측정 데이터를 Export하고 원본 보정 파일·KFactor·새 결과 파일을 선택합니다.
   Convert로 보정 파일을 생성합니다.
2. 변환 성공을 확인한 뒤 Apply로 RTC 테이블에 로드합니다. 적용한 헤드와 테이블
   번호도 확인합니다.
3. 같은 격자를 다시 가공·측정하여 잔여 XY 오차가 공정 허용치 안인지 확인합니다.
   결과 파일이 생성되었다는 사실만으로 보정 정확도를 판단하지 않습니다.

헤드·렌즈·작업 거리·기계 정렬이 바뀌면 측정을 다시 확인해야 합니다. 원본과 검증된
결과를 따로 보관합니다. 높이별 초점·가공 크기도 맞춰야 하면
[3D 보정](Correction3dUserManual.koKR.md)을 이어서 수행합니다.
