# 2D Scanner Field Correction User Manual

> 기준 버전: Sirius3 1.12.3 (공개 Release 기능)

## 1. 필드 보정이 필요한 이유

갈바노 미러의 회전은 작업면의 직선 이동과 정확히 비례하지 않으며, F-theta 렌즈의 비선형성, 광축 편심, 스캔헤드 장착 각도와 렌즈 공차가 위치별 오차를 만듭니다. KFactor만 조정하면 전체 축척은 맞출 수 있지만 배럴·핀쿠션·기울어짐과 국부 왜곡은 남습니다. 2D Field Correction은 필드 여러 위치에서 측정한 XY 오차로 이 비선형 왜곡을 줄입니다.

## 2. 준비

- 초기화된 RTC와 스캔헤드
- 현재 광학계에 맞는 원본 `.ctb` 또는 `.ct5` 보정 파일
- 낮은 출력으로 가공할 수 있는 Grid 시험 패턴
- 비전 시스템, 측정 현미경 등 실제 좌표를 측정할 장비
- 원본·측정 데이터·결과 파일을 별도로 보관할 경로

보정 작업 중 실제 레이저가 출사될 수 있습니다. 장비의 안전 절차와 시험 출력 조건을 먼저 적용하십시오.

## 3. Source, Target와 KFactor

- Source File: 현재 사용하는 원본 보정 파일
- Target File: 결과를 새 파일로 저장할 경로
- KFactor: bits/mm 단위 좌표 축척

변환식은 **Controller 위치(bit) = 사용자 입력 위치(mm) × KFactor(bits/mm)** 입니다. KFactor와 Source 보정 파일이 같은 광학 필드 기준인지 확인하십시오.

## 4. 측정 Grid

1. 홀수 Rows/Columns(예: 5×5, 9×9, 17×17)를 선택합니다.
2. Row/Column Interval(mm)을 정합니다.
3. Reset으로 Grid를 초기화합니다. 이 작업은 기존 셀 데이터를 지우므로 먼저 Export하십시오.
4. 이론 좌표의 Grid를 가공합니다.
5. 비전 또는 측정 장비로 실제 좌표를 수집합니다.

점이 많으면 국부 오차를 더 자세히 표현할 수 있지만 측정 시간과 잘못된 점의 영향도 커집니다. 성긴 Grid에서 시작해 필요한 영역만 단계적으로 늘리는 편이 안전합니다.

## 5. 오차 데이터 입력

Sirius3 1.12.3의 2D 보정 Grid는 dx/dy를 **공백 또는 쉼표**로 구분해 입력할 수 있습니다.

- `0.010 -0.005`
- `0.010, -0.005`

dx/dy는 이론점과 측정점의 차이를 보정 API가 요구하는 방향으로 넣어야 합니다. 외부 비전이 제공하는 “측정값 - 이론값”을 사용할 때 좌표축 방향, 카메라 회전·반전과 단위를 먼저 통일하십시오. 중앙과 네 모서리에 알려진 오차를 넣어 부호를 검증한 뒤 전체 데이터를 가져오는 것이 좋습니다.

1.12.3에서는 오차 거리에 따른 셀 색상이 다시 표시됩니다. 색상은 이상점을 찾는 보조 수단이며, 정확한 허용 여부는 수치와 공정 공차로 판단하십시오.

## 6. 외부 비전 데이터로 RtcCorrection2D 만들기

개발자는 비전 좌표를 행·열 순서로 정렬한 뒤 `RtcCorrection2D`에 이론 좌표와 상대 오차를 추가할 수 있습니다. Grid의 원점, 행 방향, 열 방향과 간격이 UI 표시와 일치해야 합니다. 누락점, 중복점, NaN/Infinity, 단위 불일치를 먼저 거른 후 `UI.Config.OnScannerFieldCorrection2DShow`에서 2D 보정 WinForms를 열어 검토·저장·적용합니다.

## 7. 변환과 적용

1. Import/Export로 측정 데이터를 백업합니다.
2. Convert로 Target 보정 파일을 생성합니다.
3. 오류 메시지와 결과 파일을 확인합니다.
4. Apply로 RTC 보정 Table에 로드하고 선택합니다.
5. 같은 Grid를 다시 가공·측정해 잔차를 확인합니다.

파일이 만들어졌다는 사실만으로 보정이 성공한 것은 아닙니다. 적용한 Table 번호, 현재 Primary Head, KFactor, 축 방향과 실제 잔차를 함께 확인하십시오.

## 8. 주의사항

- 원본 보정 파일을 덮어쓰지 마십시오.
- Grid 구조를 바꾼 뒤 Reset하면 기존 데이터가 지워집니다.
- 한두 개의 큰 이상점이 전체 보정면을 왜곡할 수 있습니다.
- 카메라 좌표와 스캐너 좌표 사이의 Matrix를 두 번 적용하지 마십시오.
- 보정 결과는 해당 스캔헤드·렌즈·작업 거리·장착 상태의 조합에만 유효합니다.
