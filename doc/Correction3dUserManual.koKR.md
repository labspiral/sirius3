# Integrated 3D Calibration User Manual

> API 기준: Sirius3 Core/UI 1.17.2 (공개 기능)
> 6장에서는 1.17.2 보정 화면을 설명합니다.

[English](Correction3dUserManual.md) | [한국어](Correction3dUserManual.koKR.md) | [전체 안내서](README.koKR.md)


## 1. 시스템 준비

호환 RTC, 3D 초점 스캐너와 설치에 맞는 CalibrationLibrary 런타임을 사용합니다.
원본 `.ctb` 또는 `.ct5`, 대응 README, 정확한 KFactor(bits/mm)를 준비합니다.
원본 파일을 보관하고 각 보정 결과는 별도 이름으로 저장합니다.

처음에는 [공개 데모를 가상 장치로 설정](../demos/editor_fieldcorrection_3d/README.koKR.md)해
화면을 익힙니다. 실제 장비에서는 승인된 절차에 따라 이동과 초점을 조작합니다.

## 2. 측정 순서

1. 빔 기울기를 조정해 두 높이의 중심 이동을 보정한 뒤 Z=0에서 XY 위치를 보정합니다.
2. Z=0 평면의 초점을 맞춘 뒤 여러 높이의 측정값으로 ABC 계수를 구합니다.
3. 높이에 따라 가공 크기가 달라지는 광학계는 스트레치를 보정합니다. ABC와
   스트레치는 Z=0 초점 이후 어느 순서로 진행해도 됩니다.

각 단계에서 검토한 결과를 적용하고 다음 단계의 원본으로 사용합니다.
장치 조작과 파일 적용 방법은 [통합 3D 보정 절차](#6-통합-3d-보정-절차)를 참고합니다.

## 3. A·B·C 계수를 이해하는 방법

초점 테이블은 `Zout = A + B × l + C × l²`로 표현합니다. 그래프의 가로축은
컨트롤러의 초점 거리 편차 입력 `l`, 세로축은 출력 `Zout`입니다.

| 값 | 역할 |
|---|---|
| A | l=0에서의 출력이며 곡선을 위·아래로 이동합니다. |
| B | l이 변할 때 출력이 변하는 기울기입니다. |
| C | 기울기의 변화량이며 0이면 직선, 0이 아니면 포물선이 됩니다. |

`l`은 높이 Z(mm) 자체가 아닙니다. 컨트롤러가 요청 좌표를 초점 입력으로 바꾸므로
mm 값을 그대로 대입하지 않습니다. `FocusCalibrationCoeffABC`는 측정한 입력·출력
쌍으로 계수를 구하고 `GetCoefficient`는 파일의 계수를 읽습니다.

보정 측정 배열은 CTB에서 16비트, CT5에서 20비트 단위를 사용합니다. 파일에서
반환하는 A·B·C는 두 형식 모두 16비트 호환 다항식 기준입니다. 같은 물리 초점에
대하여 `L20 = 16 × L16`, `Zout20 = 16 × Zout16`이며, 계수는
`A20 = 16 × A16`, `B20 = B16`, `C20 = C16 / 16`로 대응합니다. 측정표는
RTC4·RTC5에서 부호 있는 16비트, 표준 RTC6 3D에서 부호 있는 20비트 값을
표시합니다. 표시된 단위로 입력하면 원본 파일 기준으로 변환합니다.

## 4. 가져온 표면의 초점 보정

1. `IDocument.ActImport`로 STL 등의 메쉬를 가져옵니다.
2. `ActPointCloud` 또는 `ActGridCloud`로 표면 점을 추출합니다. 곡률이 큰 곳은 격자
   간격(mm)을 줄이고 카메라를 약간 기울여 표면을 제대로 나타내는지 확인합니다.
3. 모델을 실제 작업물 좌표에 맞춘 뒤 XYZ 점군과 원본 보정·README 파일을
   `RtcCalibrationLibrary.PointsCloudCalibration`에 전달합니다. 결과는 별도 파일로
   저장하고 반환 코드와 실제 표면 초점을 확인합니다.

점군은 내부 체적이 아니라 표면입니다. `ActGridCloud`의 법선은 샘플 확인에 유용하며
보정 함수에는 점 위치를 전달합니다. [표면 점군](EntityUserManual.koKR.md)을 참고합니다.

## 5. 저장·적용 후 확인

측정표를 변경하기 전에 측정 데이터를 저장합니다. 검토한 보정 결과를 적용한 뒤
선택된 헤드와 테이블을 확인하고 대표 지점에서 다시 측정합니다. 렌즈, 작업 거리,
설치 상태가 달라지면 초점과 치수를 다시 확인합니다.

## 6. 통합 3D 보정 절차

WinForms와 WPF 보정 창에는 같은 다섯 측정 탭이 있습니다. 원본 테이블과 대응
README, KFactor를 지정합니다. 측정점 조작 전에 원본 파일 옆 상단의 **로드**로
RTC에 원본 테이블을 선택합니다. **추가**, **제거**, **비우기**로 표를 편집하고,
측정 파일은 우클릭 메뉴에서 가져오거나 내보냅니다. 행 선택과 셀 편집으로 데이터를
준비한 뒤 장치 조작은 해당 탭의 **선택점으로 이동**과 **초점값 적용**으로 실행합니다.

| 단계 | 측정 및 확인 방법 |
|---|---|
| **빔 기울기** | 지령 X=Y=0에서 원본 테이블의 축을 기준으로 Z=0, Z=+Height 순서로 스폿 중심을 측정합니다. `Dx = X(0) − X(+Height)`, `Dy = Y(0) − Y(+Height)`를 mm로 입력합니다. Height는 0보다 크고 README의 양의 Z 한계 이하여야 합니다. 범위 안에서도 `CALCULATION_FAILED`가 발생하면 대응 README, 단위, 실측 중심 차를 확인합니다. 결과 적용 후 두 평면을 다시 측정합니다. |
| **XY 필드** | Z=0에서 필드 전체에 목표점을 세 곳 이상 배치합니다. 목표점과 같은 원점·축으로 실측 X/Y를 mm 단위로 입력합니다. 결과를 로드한 뒤 기준점 위치를 다시 측정합니다. |
| **Z=0 초점** | 소재를 Z=0에 두고 필드 전역의 초점을 측정합니다. 3×3 격자를 권장합니다. 각 행의 위치로 이동하고 가장 선명한 초점값을 `Zout`에 기록합니다. 조절한 값을 시험하려면 **초점값 적용**을 사용합니다. |
| **ABC 초점** | 각 높이에서 **선택점으로 이동**하면 RTC가 계산한 `L`을 읽습니다. **거리값 L 읽기**로 해당 행의 값을 다시 읽을 수 있습니다. XYZ와 L을 유지한 채 `Zout`을 조절합니다. CTB/CT5 비트 기준으로 바꾼 뒤에도 서로 다른 L 값이 세 개 이상이어야 합니다. 측정 파일의 `A` 열에는 실측 `Zout`이 들어가며, 결과의 계수 `A`는 `B`, `C`와 함께 표시됩니다. |
| **스트레치** | 서로 다른 0이 아닌 Z 높이를 두 곳 이상 사용합니다. 가능한 경우 양·음 높이를 포함합니다. 목표 XYZ와 실측 XY는 절대 위치를 mm로 입력합니다. 결과를 로드한 뒤 같은 높이의 목표점을 다시 측정해 XY 크기를 비교합니다. |

각 단계는 직전에 검토하고 적용한 테이블을 기준으로 측정합니다. ABC와 스트레치의
Z는 같은 Z=0 기준면으로부터의 부호 있는 절대 높이입니다. 소재 높이는 장비 절차에
따라 맞춥니다. 스캐너 이동은 스캔 헤드와 광학 초점에 적용됩니다. 단계 전환과 창
닫기 시 임시 초점값을 복원합니다. 빔 기울기 측정값이 이미 있으면 RTC 카드 없이
파일을 계산할 수 있습니다.

### 계산·검토·로드

1. 원본과 확장자가 같은 별도 대상 경로를 지정합니다. 현재 탭이 파일명을 제안하며,
   직접 입력한 경로는 탭을 바꿔도 유지됩니다.
2. **계산 및 파일 저장**을 누릅니다. 화면은 저장 파일을 다시 읽어 확인하고 경로를
   표시합니다. **파일 값 비교**로 원본과 결과를 검토합니다. ABC 탭은 계산 뒤
   측정점과 저장된 보정식의 곡선을 표시합니다. 입력, 경로 또는 저장 파일을 바꾸면
   로드 전에 다시 계산합니다. **ABC 단위·비트 비율**에서 RTC와 파일의 비트 기준을
   확인합니다.
3. 마커와 RTC가 대기 상태일 때 탭 하단의 **로드**를 누르고 확인합니다. 적용한 결과가
   새 원본이 되며 대응 README가 있으면 함께 지정됩니다. 예를 들어 `D3_2982_BeamTilt.ct5`를
   로드하고 XY 필드 탭을 열면 `D3_2982_BeamTilt_XyField.ct5`가 제안됩니다. 다음 단계로
   넘어가기 전에 관련 지점에서 다시 측정합니다.

### 수동 Z 범위와 조그

Is3D가 켜져 있고 주 헤드 테이블의 대응 README에서 Z 범위를 읽을 수 있으면 수동 제어
하단에 범위가 표시됩니다. 좌표 변환 후 Z가 범위를 벗어나는 XYZ 이동은 경고 후
취소됩니다. 조그 창의 XY 패드 옆 세로 슬라이더는 위가 +Z, 아래가 −Z입니다. 마우스를
놓으면 이동하며, 이후 XY 조그에서도 그 Z가 유지됩니다. 이는 지령값(mm)이며 실측 위치나
기계식 Z 스테이지 위치를 나타내지 않습니다.
