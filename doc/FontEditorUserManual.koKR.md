# Font Editor 사용 설명서

> API 기준: Sirius3 Core/UI 1.17 (공개 기능)

[English](FontEditorUserManual.md) | [한국어](FontEditorUserManual.koKR.md) | [전체 안내서](README.koKR.md)

## 1. Font Editor 열기

WinForms 또는 WPF 편집기 화면에서 우클릭하여 **Stitched image** 아래의
**Font Edit**를 선택합니다. SiriusText 개체를 먼저 선택하면 해당 폰트 파일을 엽니다.
폰트 편집은 도면 문서와 독립적이며 마킹 장치를 조작하지 않습니다. 폰트 편집의
Undo/Redo는 문서 이력과 별도로 동작합니다.

기존 파일은 **열기**, 새 CXF·LFF·DOT는 **신규**를 사용합니다. 기존 EO ASCII/binary
FNT는 열기·편집을 지원하지만 신규 메뉴에서는 제공하지 않습니다. 창 제목에 폰트 이름과
확장자가 표시됩니다. 다른 폰트를 열거나 닫기 전에 미저장 변경을 처리하십시오.

## 2. 포맷과 단위

| 포맷 | 편집과 저장 |
|---|---|
| CXF | mm 벡터 경로이며 지원하는 원래 선·호·폴리라인을 유지합니다. |
| LFF | 폴리라인과 Bulge 호를 편집하며 편집하지 않은 문자의 참조를 유지합니다. |
| EO ASCII / binary FNT | 정수 좌표의 선 경로입니다. 지원하지 않는 가져온 곡선은 근사하고 저장 격자로 반올림합니다. |
| DOT | 정수 픽셀 셀입니다. 픽셀/mm 보기 전환은 표시 좌표를 바꾸고 저장한 실제 픽셀 간격을 유지합니다. |

Y=0이 기준선입니다. BBox는 폰트의 허용 영역이며 ascent·descent·x-height가 그 안에
들어가야 합니다. 벡터의 좌표·메트릭은 mm, DOT 픽셀 보기에서는 정수 픽셀을 사용합니다.
화면의 자릿수 표시는 원본 좌표 정밀도를 줄이지 않습니다. DOT는 정수 격자를 유지하고
안티앨리어싱 없이 표시합니다.

## 3. 문자·경로·정점 선택

좌측 **문자**에서 대상을 선택하고 가운데 캔버스에서 편집하며 우측 표에서 경로·정점
순서를 확인합니다. 구분선을 끌어 영역 너비를 조정할 수 있습니다. 처음에는 Latin을
표시하며 BMP 블록 또는 문자·코드를 입력해 이동합니다. Ctrl+PageUp/PageDown은
이전/다음 문자, Ctrl+Shift+G는 문자 목록으로 포커스를 이동합니다. 문자 목록의
방향키는 목록 탐색에 사용하며 캔버스를 움직이지 않습니다.

| 문자 상태 | 의미 |
|---|---|
| 비어 있음 / 회색 | 사용할 문자 형상이 없습니다. |
| 편집 중 / 파랑 | 저장한 데이터와 다릅니다. |
| 완료 / 초록 | 현재 형상을 완료 상태로 표시했습니다. |
| 저장됨 / 짙은 회색 | 저장한 문자 데이터와 같습니다. |

주황색 테두리는 현재 문자를 나타냅니다. **완료**는 진행 상태 표시이며 실제 파일
기록은 **다른 이름으로 저장**으로 실행합니다. 공백 폭은 일반 문자 형상을 추가하는
방식 대신 SiriusText에서 설정합니다.

## 4. 그리기와 정점 편집

포맷이 지원하는 선택·선·폴리라인·원·타원·호·DOT 도구를 사용합니다. 빈 벡터 문자는
폴리라인, DOT 문자는 픽셀 그리기로 시작합니다. DOT 셀을 클릭하면 점을 켜거나 끕니다.
원·타원·호는 별도 도구입니다. 타원은 중심과 바깥 사각형 모서리, 호는 중심·시작·끝
순서로 입력하며 Ctrl로 호의 진행 방향을 바꿉니다. 폴리라인에서 A는 선/호 전환,
Enter는 입력한 점으로 완료, Backspace는 이전 단계, Escape는 취소입니다.

경로·정점을 클릭해 선택하고 Ctrl/Shift로 선택을 확장합니다. 선택한 항목을 끌어
이동하거나 빈 공간을 드래그해 사각 영역을 선택합니다. 우측 표에서 좌표·Bulge 편집,
정점 삽입·삭제, 경로 뒤집기와 열림/닫힘을 조정합니다. 행을 끌어 같은 경로의 정점
순서를 바꾸고 경로 전체를 선택하여 경로 순서를 바꿀 수 있습니다. Undo/Redo를 지원합니다.

새 점과 일반 이동은 BBox 안에 유지되며 경계에서 멈춥니다. 이미 BBox 밖에 있는
형상에는 **클리핑**을 명시적으로 적용하고 저장 전 결과를 확인하십시오. CXF/LFF는
지원하는 원래 호를 보존합니다. FNT 곡선은 ascent의 0.01%(0이면 BBox 높이) 오차로
근사하며 저장 격자의 반올림 오차가 추가됩니다.

## 5. Grip·스냅·화면 이동

선택한 벡터 경로에서 **Tab**는 Move → Vertex → Scale, **Shift+Tab**는 역순으로
전환합니다. 지원하지 않는 모드는 건너뜁니다. 직선 두 점 경로는 Move·Vertex를
사용합니다. 다른 경로 또는 문자를 선택하면 Move로 시작합니다.

| 모드 | 조작 |
|---|---|
| Move | 중심·경계 Grip으로 경로 전체 이동 |
| Vertex | 원본 정점과 Bulge 편집 |
| Scale | 경로 전체 크기·회전 조정 |

V/Shift+V으로 다음/이전 Grip을 선택합니다. 드래그하면서 좌측 상단의 좌표·크기·
각도·Bulge 값을 확인합니다. Escape는 미리보기를 취소하고 완료한 드래그는 Undo
한 건으로 기록합니다. 표에서 일부 정점만 선택했어도 전체 경로의 Move·Scale Grip은
그 경로 전체에 적용됩니다.

**G**는 점·가이드에 대한 자석 스냅을 켜거나 끕니다(기본 켜짐). 선택 거리는 기준
3픽셀에 DPI를 적용하며 줌과 무관합니다. 이동·각도 격자와는 별도입니다. 지원하는
위치·크기 관련 이동은 보조 키 없이 연속적으로 조정합니다. Ctrl / Ctrl+Alt /
Ctrl+Alt+Shift는 호스트의 기본 **1 / 0.1 / 0.01 mm** 간격을, 회전은
**90 / 10 / 1°** 간격을 사용합니다. Shift 드래그는 가까운 축, Alt 단독은 세로 축,
X/Y는 해당 축을 고정합니다. Ctrl 조합은 격자만 선택하고 축을 추가로 고정하지 않습니다.
DOT는 정수 픽셀 격자를 항상 유지합니다.

휠은 포인터 기준 확대·축소, 가운데/오른쪽 드래그는 화면 이동입니다. F·Ctrl+F·Home은
화면 맞춤입니다. 일반 방향키는 캔버스를 움직이며 Ctrl 조합의 방향키는 선택 정점을
다음 격자 경계로 이동합니다. Ctrl+[ / ]는 설정한 각도 간격의 시계/반시계 회전입니다.

## 6. BBox·메트릭·배율·가이드

**BBox / 메트릭**(Ctrl+Shift+M)에서 폰트 이름·영역·ascent·descent·x-height를
설정합니다. 영역을 줄이면 일부 문자의 클리핑이 필요할 수 있으므로 적용 전 확인합니다.
**배율** 탭은 배율 또는 목표 기준 높이를 입력하며 폰트 전체에 Undo 한 건으로
적용합니다. DOT는 정수 셀 인덱스를 유지하고 실제 mm 간격을 바꿉니다.

가이드 메뉴나 Shift+H/Alt+V로 수평/수직 가이드를 추가합니다. 선택한 가이드를
드래그하거나 F2로 위치를 입력하고 Delete로 제거합니다. Ctrl+Shift+H는 모두 제거합니다.
가이드는 프로그램 공통 보기 설정이며 폰트 파일 내용에는 포함되지 않습니다.

## 7. 미리보기·DXF·TTF 변환

Ctrl+Shift+P로 **문자열 미리보기**를 열고 테스트 문자열을 입력합니다. 실제 SiriusText
속성으로 간격·고정 셀 폭·문자 폭 맞춤·여러 줄 배치를 조정합니다. 대문자·하강 문자·
공백과 사용할 크기를 확인하십시오. 미리보기 창에는 자체 화면 맞춤과 항상 위 옵션이 있습니다.

Ctrl+I로 현재 문자에 DXF를 가져옵니다. 적용 전 단위·BBox·경로 순서와 포맷에 따른
곡선 변환을 확인합니다.

Ctrl+Shift+C는 설치 TrueType의 **폰트 변환기**를 엽니다. 스타일·출력 포맷과 지원
BMP 블록을 선택하며 Basic Latin이 기본 선택입니다. EO binary는 U+0000~00FF로
제한됩니다. 벡터는 기준 높이(mm)와 곡선 구간 최대 길이(기본 0.02 mm)를 사용하고
근사 오차는 높이의 0.01%로 계산합니다. BBox 폭 **0**은 자동이며 양수를 지정하면
변환 형상을 모두 포함해야 합니다. DOT는 정수 래스터 크기와 Light/Normal/Bold 픽셀
굵기를 사용합니다. 필요한 변환 실행 파일이 프로그램의 Sirius 폰트 폴더에 있어야 합니다.

## 8. 저장과 재사용

Ctrl+S와 Ctrl+Shift+S는 모두 **다른 이름으로 저장**을 실행합니다. 대상 기존 파일은
`.bak`로 백업하고 이전 백업은 별도로 보관합니다. 저장 실패 시 원본을 유지합니다.
파일이 외부에서 변경되었다면 오래된 편집 상태로 덮어쓰지 말고 다시 열어 조정하십시오.
큰 변경 전 별도 사본을 유지하는 것이 좋습니다.

저장한 파일은 EntitySiriusText·EntityCircularSiriusText에서 사용합니다. 저장·변환에
성공하면 현재 프로그램의 같은 폰트를 사용하는 텍스트를 갱신합니다. 폰트 저장은 문서
Undo/Redo에 포함되지 않습니다. 다른 설치에서도 찾을 수 있도록 레시피와 함께 또는
설정된 Sirius 폰트 폴더에 보관합니다.

## 9. 주요 단축키

| 키 | 동작 |
|---|---|
| Ctrl+N / O / S | 신규 / 열기 / 다른 이름으로 저장 |
| Ctrl+Z / Y | 실행 취소 / 다시 실행 |
| V (선택 경로 Grip이 없을 때) / L / P / C / Alt+E / A / D | 선택 / 선 / 폴리라인 / 원 / 타원 / 호 / DOT |
| Tab / Shift+Tab | 다음 / 이전 Grip 모드 |
| V / Shift+V | 다음 / 이전 Grip |
| G | 자석 스냅 켜기/끄기 |
| F / Ctrl+F / Home | 화면 맞춤 |
| Ctrl+Shift+P / M / R / C | 문자열 미리보기 / 메트릭 / 폰트 배율 / TTF 변환기 |
| Ctrl+I | DXF 가져오기 |
| F4 / Shift+F4 | 가공 순서 / 점프 경로 표시 |
| Ctrl+Shift+X | DOT 픽셀/mm 좌표 표시 전환 |
| F1 | 키보드 도움말 |

그리기 문자 키와 Grip 키는 캔버스에 적용됩니다. 텍스트 입력과 정점 표에서는 일반
입력·편집 키를 유지합니다. 여기서 F4는 순서 표시이며 도면 편집기의 장치 미리보기와
구분합니다.

## 10. 프로그램에 연결하기

`SpiralLab.Sirius3.UI.FontEditor.FontEditorForm`을 별도 창으로 열거나 WinForms
컨테이너에 `FontEditorControl`을 배치합니다. 공개 비동기 메서드는 `OpenFontAsync`,
`NewFontAsync`, `SaveFontAsync`, `ConfirmCloseAsync`입니다.

```csharp
var window = new SpiralLab.Sirius3.UI.FontEditor.FontEditorForm();
window.Show(this); // this는 소유 WinForms Form입니다.
bool opened = await window.Editor.OpenFontAsync(@"C:\Fonts\romans.cxf");
```

파일 작업은 소유 UI 스레드에서 호출합니다. 사용자 컨테이너에 직접 배치한 경우에는
취소 가능한 종료 이벤트에서 `ConfirmCloseAsync()`를 기다리고 허용되면 컨트롤을
해제합니다. WPF에서도 뷰포트의 우클릭 메뉴로 같은 편집기를 엽니다.
[텍스트](TextUserManual.koKR.md), [편집기](EditorUserManual.koKR.md),
[WinForms](WinForms.koKR.md), [WPF](WPF.koKR.md)를 함께 참고하십시오.




## 생성과 Vertex 모드 키

Ellipse 생성 중 Shift 단독은 원 비율로 미리보기합니다. 생성이 끝나면 비율 제한을 유지하지 않으며 Ctrl+Shift·Alt+Shift는 비율을 제한하지 않습니다.

캔버스의 Vertex 모드에서 Insert는 포인터 아래 직선·호를 분할하고 Delete는 가리키거나 V로 고른 정점을 삭제합니다. 열린 경로는 2개, 닫힌 경로는 3개를 남기며 호의 Bulge와 Undo/Redo를 보존합니다. 정점 표와 다른 모드의 기존 선택 삭제·중점 삽입·연속 그리기 명령은 유지됩니다. DOT와 가이드 삭제는 기존 규칙을 따릅니다.

`Tab: Move mode` / `Tab: Vertex mode` / `Tab: Scale mode`, `V: Next grip` 안내를 확인하십시오. Shift+Tab은 이전 모드, Shift+V는 이전 Grip이며 세로 가이드 추가는 Alt+V입니다. 보조 Bulge 제어점은 정점보다 작고 채움이 더 투명합니다.
