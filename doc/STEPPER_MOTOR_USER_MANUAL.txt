[Sirius3] RTC Stepper Motor Control User Manual
==================================================

1. 개요 (Overview)
------------------
본 매뉴얼은 SCANLAB RTC5/6 제어기의 스테퍼 포트(Stepper Port)를 통해 최대 2개의 모터를 제어하는 Sirius3 StepperControl의 사용 방법을 설명합니다. 이 기능은 주로 로터리 인덱스(회전축) 구동이나 XY 스테이지의 분할 이송(Step-and-Repeat) 작업에 사용됩니다.

2. 시스템 준비 및 설정 (Setup)
----------------------------
- RTC 카드 뒷면의 STEPPER 포트에 스테퍼 드라이버가 연결되어 있어야 합니다.
- 단위계 설정: 각 축별로 MilliMeter(선형 축) 또는 Degree(회전축) 단위를 지원합니다.
- 스케일 팩터(Scale Factor): 1mm(또는 360도) 이동을 위해 필요한 펄스(Step) 수를 정확히 설정해야 실좌표 이동이 가능합니다.

3. 상태 모니터링 (Status Indicators)
----------------------------------
UI 상단에서 각 모터의 실시간 상태를 확인할 수 있습니다.
- Pos / Vel: 현재 절대 위치 및 이동 속도 표시.
- Busy: 위치 이동 또는 가공 명령이 수행 중일 때 점등.
- Init: 원점 복귀(Reference Run)가 진행 중일 때 점등.
- Limit: 리미트 스위치가 감지되었을 때 빨간색으로 점등.
- Home (L): 원점 복귀가 성공적으로 완료되어 좌표계가 초기화되었음을 의미.

4. 원점 복귀 (Reference Run / Homing)
------------------------------------
정밀한 위치 제어를 위해 장비 가동 전 반드시 원점 복귀를 수행해야 합니다.
- 1차 탐색(Vel 1): 지정된 방향으로 이동하며 리미트 스위치를 탐색합니다.
- 이탈 및 2차 탐색(Vel 2): 스위치 감지 후 정해진 공차(Tolerance)만큼 빠져나온 뒤, 저속으로 정밀하게 다시 탐색하여 원점 위치를 확정합니다.
- Home Position: 탐색 완료 후 해당 지점에 부여할 좌표값을 입력합니다.

5. 위치 이동 명령 (Movement Control)
-----------------------------------
- Enable: 모터의 구동 전류를 인가하거나 차단합니다. (체크 해제 시 고정 토크가 풀리므로 주의)
- Disable Switch: 회전축처럼 360도 무한 회전이 필요한 경우 리미트 스위치 감지를 무시하도록 설정할 수 있습니다.
- Move List: 자주 사용하는 좌표와 속도를 최대 20개까지 리스트로 관리할 수 있습니다.
  * Absolute: 설정된 원점 기준 절대 좌표로 이동.
  * Relative: 현재 위치 기준 상대 거리만큼 이동.
  * Drag-and-Drop: 리스트 내의 항목 순서를 마우스로 드래그하여 변경 가능합니다.

6. 중요 주의 사항 (Safety Warnings) - 필독
-----------------------------------------
1) 탈조(Step-out) 주의: RTC 카드의 스테퍼 제어 기능에는 '가감속 프로파일(Ramp-down)' 기능이 내장되어 있지 않습니다. 
급격한 속도 변화는 모터의 탈조를 유발할 수 있으므로, 하드웨어 드라이버 자체의 필터 기능을 사용하거나 소프트웨어에서 적절한 속도를 지정하십시오.
2) 비상 정지(Abort) 독립성: RTC 카드의 가공 중지 명령(CtlAbort)은 스테퍼 모터의 동작을 멈추지 않습니다. 
비상 상황 시에는 반드시 'STOP' 버튼을 별도로 클릭하거나 `CtlStepperMoveStop` 명령을 호출하여 모터 펄스 출력을 강제 차단해야 합니다.
3) 유지 토크(Holding Torque) 소실: 모터 Enable을 해제(Reset)하면 모터에 흐르는 전류가 차단되어 위치를 유지하는 힘이 사라집니다. 
Z축(수직축) 제어 시에는 자중에 의해 축이 흘러내릴 수 있으므로 (브레이크 기능이 있는지 여부를 확인) 각별히 주의하십시오.

7. 설정 저장 (Data Persistence)
------------------------------
- 입력한 원점 복귀 파라미터 및 Move List 데이터는 윈도우 레지스트리에 자동 저장되어, 프로그램 재시작 시에도 유지됩니다.
