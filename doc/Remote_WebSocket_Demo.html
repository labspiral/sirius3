Protocol Manual

System Info

  • Separator: ,
  • Terminator: ;
  • Success: OK;
  • Error: NG;

Marker Control

  • Start: marker,start;
  • Stop: marker,stop;
  • Reset: marker,reset;

Status & Recipe

  • Status: status;
  • Recipe: recipe;
  • Load Recipe: recipe,{Name};

Offset

  • Get Offset: offset;
  • Set Offset: offset,1,X,Y,Z,A;
  • Set Offsets: offset,2,X1,Y1,Z1,A1,X2,Y2,Z2,A2;

Text

  • Get Text: text;
  • Set Text: text,1,{Text};
  • Set Text (K|V): text,1,K,V;
  • Batch Text: text,2,K1,V1,K2,V2;

Property Control

  • Read: target,{Name},{PropertyName};
  • Write: target,{Name},{PropertyName},{Value};
  • List: target,{Name},properties;

* target: layer, entity, entitypen, layerpen.
